# Завдання 3 · Взаємодія (Sequence) · Бібліотека

Розвинуто UC-05 «Оформити видачу примірника» із Завдання 2 **без зміни бібліотечного домену**. Підстава: [ER-модель ЛР1](https://github.com/Alex9011/Lab1_KPI2/blob/master/spec.md), `Book`, `Author`, `Copy`, `Member`, `Loan`.

## Файли

- [`spec.md`](spec.md) — UC, точні Gherkin зі Завдання 2, учасники, кроки, джерела/рендери, аудит, топ-3 ризики.
- [`DEFENSE.md`](DEFENSE.md) — заповнений текст під шаблон на зображенні, місця для реальних URL PR і SHA-комітів.
- [`sequence/`](sequence/) — вісім `Mermaid sequenceDiagram` (S-01 … S-08).
- [`render/`](render/) — вісім SVG і вісім PNG, автоматично отриманих із `.mmd`.
- [`ai/`](ai/) — задача, аналіз помилок, історія промтів, локальний генератор і перевірка.

## Як подивитися

Відкрийте файли `.svg` або `.png` у папці `render/`; джерела Mermaid можна переглянути в GitHub і [Mermaid Live](https://mermaid.live/). Локальний рендерер підтримує лише підмножину Mermaid, яка використана в цій роботі; рендери породжені саме ним.

## Відтворення та контроль

```bash
python ai/render.py
python ai/check.py
```

Для PNG скрипт потребує `cairosvg` (інакше згенерує SVG). Інші залежності — стандартна бібліотека Python.
